# 全キャラクターを 32×32 にして、コマを増やす

ブランチ：`sprite-hires`（master には未反映。ユーザーの確認待ち）
前の段階：`2026-11-11_owl_sprite_32px_trial.md`（フクロウ1体の試作）

## 対象

- `src/content/sprites.ts`（新規：絵とポーズのデータ）
- `src/components/Sprite.tsx`（描画だけに）
- `src/components/Scene.tsx`（コマの並び・コマ送り）
- `src/content/world.ts`（パレット）
- `src/app/globals.css`（息づかい・跳ねる動き）
- `src/app/sprites/page.tsx`（確認用の一時ページ）
- 顔の大きさの変更：`ClosingPanels`・`ExamPanel`・`GameApp`・`JournalInput`・`LessonView`・`MockExamPanel`・`Panels`・`PracticePanel`・`TrainingPanels`

## 変更内容

- 人・ドワーフ・妖精も 32×32 に描き直した（髪の影と光、ほおの影、目の光、かぶとの縁、ひげの流れ、羽の縁を足した）。
  人は今までどおり1つの絵をパレットで塗り分ける。髪の影と光は `shade()` で元の色から作る。
- 絵とポーズのデータを `src/content/sprites.ts` に分けた。`Sprite.tsx` は描くだけ。前の絵（`owl16`）と `sym16` は消した。
- コマを増やした（昔の格闘ゲームのように、動きの前後に「ため」と「のび」を入れる）。
  - 歩く：4コマ → 8コマ（上げかける → 上げて傾く → 一歩下ろして沈む → 元の絵、を左右で）
  - 正解・昇格：かがむ（浅く・深く）→ のび上がる → 両手を上げきる → 下りてくる → 着地で沈む
  - 話す身ぶり：1コマ → 2コマ（上げかける → 上げる）
  - 考える：1コマ → 3コマ（上を見て、頭を左 → まんなか → 右）
  - 眠る：1コマ → 4コマ（おなかが上下し、Z がのぼっていく）
  - あわてる：1コマ → 3コマ（すくんで、汗のしずくが流れる）
- 待機の動きを、体ごとの上下から「息づかい」に変えた（上半身が沈み、少し遅れて頭が沈む。4段階・1.6秒）。
  妖精だけは今までどおり体ごと浮く。
- ポーズの作り方を足した：`stamp`（小さな絵を重ねる）・`stretch`（のびる）・`lean`（傾く）・`lift`（一部を上げ下げ）・`recolor`。
  左右反対のコマは `flip` で作るので、片側だけ書けばよい。
- コマ送りを「予定の時刻」で数えるようにした（タイマーの遅れがたまらず、CSS の動きとずれない）。
  歩いてくる間は、場面の動き（跳ねる・震える）を始めない。
- 同じ色が横に続くドットを1つの `<rect>` にまとめた（1体あたり約1000個 → 約200個）。
- 顔の大きさを 16 の倍数にそろえた（44→48、56→64、72→64、88→96、24→32、棚の上の師匠 36→32）。ドットの幅がそろう。
- `/sprites` を作り直した：全員・大きさ別・動き（ゲームと同じコマ送り）・店の場面（話し手と動きをボタンで切り替え）・全コマ。

## 理由

「ピクセルの大きさはいい感じ。コマをもう少し増やしてなめらかに。昔のストリートファイターのような感じ」という要望。
借りたのは動きの付け方（ため・のび・着地の沈み、待機の息づかい）だけで、絵はすべてこのゲームのもの。

## 確認したこと

- `npx tsc --noEmit`：エラーなし
- `npm test`：8ファイル・102件すべて成功
- `/sprites` とタイトル画面を Chrome で表示（コンソールのエラーなし）。店の場面で、話し手4種類と棚の上の師匠の動きを確認
- 確認に使った Chrome はウィンドウが隠れていて描画が 1秒に1コマほどしか進まなかったので、
  動きのなめらかさ・速さは静止画でしか見ていない。ユーザーの画面で見てもらう
