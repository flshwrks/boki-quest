# フクロウのドット絵を 32×32 に（試作）

ブランチ：`sprite-hires`（master には未反映。ユーザーの確認待ち）

## 対象

- `src/components/Sprite.tsx`
- `src/components/Scene.tsx`
- `src/content/world.ts`
- `src/app/sprites/page.tsx`（新規・一時ページ）

## 変更内容

- ホーホー先生（owl）を 16×16 から 32×32 に描き直した。左半分だけ描いて左右対称にする仕組みはそのまま。
  色を5つ足した（羽の濃淡 `d`・`t`、足の影 `n`、目のいちばん下の行 `W`・`K`）。
- 歩くコマを 2コマ → 4コマにした（`walk1`〜`walk4`：片足を上げて傾く → 下ろす → 反対の足を上げる → 下ろす）。
  人・ドワーフは `walk1`・`walk3` だけ足を開くので、見た目は今までと同じ。
- フクロウに「かがむ」のコマを足した（今まではなかったので、正解のときも跳ねるだけだった）。
- ポーズの作り方を広げた。ドットの差し替え（`Edit[]`）に加えて、絵全体の変換（`Transform`）も書ける。
  - `run(x, y, "文字列")`：横に並んだドットをまとめて差し替える
  - `sym(幅)`：左右対称に差し替える（`sym16`・`sym32`）
  - `chain`・`flip`・`squash`・`eyesShut`：重ねる・左右反転・行を詰める・目を閉じる
- まばたきは、目のいちばん下の行だけをまぶたの線にする（大文字の `W`・`K`）。
- 口パクの位置を「行と文字」から `[x, y, 幅]` に変えた（32×32 で口の幅が変わるため）。
- 見比べ用の一時ページ `/sprites` を作った（前の絵と新しい絵を、ふだんの絵・大きさ別・全ポーズ・動きで並べる）。
  そのために `Scene.tsx` の `CLIPS`・`ENTER`・`Clip` を export し、前の絵を `owl16` として残している。

## 理由

キャラクターのドットを細かくし、コマを増やして動きを滑らかにしたい、という要望。
全員を一度に描き直すと手戻りが大きいので、まずフクロウ1体で絵柄と動きを確かめてもらう。

## 確認したこと

- `npx tsc --noEmit`：エラーなし
- `npm test`：8ファイル・102件すべて成功
- `/sprites` とタイトル画面をブラウザで表示して、絵と動きを目で確認（コンソールのエラーなし）

## 残作業

- ユーザーの OK をもらってから、人・ドワーフ・妖精を 32×32 に描き直し、ポーズを広げる
- 全員を描き直したら消すもの：`SPRITES.owl16`・`BLINK.owl16`・`POSES.owl16`・`MOUTH.owl16`、
  `src/app/sprites/`、`Scene.tsx` の `CLIPS`・`ENTER`・`Clip` の export、`sym16`
- 話し手の大きさ 88px は 32 の倍数でないので、ドットの幅がそろわない（1ドット = 2.75px）。
  64 か 96 にするとそろう。どちらにするかはユーザーと決める
- 32×32 は四角（`<rect>`）の数が約4倍になる。重くなるようなら、同じ色が横に続くところを1つにまとめる
